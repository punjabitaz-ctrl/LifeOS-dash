## Checked and sound

- DOM sinks: no innerHTML, outerHTML, insertAdjacentHTML, document.write, srcdoc, eval, new Function or string timers in app.js or sync-ui.js. `h()` writes text with textNodes or `textContent`, `value` as a property, and attributes only from keys written in code; `on*` keys attach listeners. The only `href` is the blob URL in `download()`. SVG attributes are numbers computed in code. No `style` attribute or CSSOM style writes, so no CSS injection. The one string-built selector (app.js:448) uses whitelisted module ids.
- CSP: build hashes the single inline script and style; no inline handlers or style attributes; smokes and review-ui saw no CSP console errors.
- No confirm, alert or prompt. No em or en dashes in app.js, sync-ui.js, styles.css or shell.html.
- Write routing: every UI write goes through `commit()` to `L.priv.write`; exceptions are deliberate (`L.priv.commit` for wellbeing check-ins, `L.priv.write` for moving old mood entries, store lifecycle calls). Core `split` makes new records that reference or are derived from private records private (SEC-62).
- Layout: drag, Move up/down, Hide/Show, size and Reset write only `settings.layouts[narrow|wide]` through `L.layout.set/reset`; ids are whitelisted, unknown dropped, caps enforced, viewport key validated; a malformed list falls back to default.
- Private close (onClose) drops the dialog, notice, CSV and ledger state, private search, toggle and view sub-state (person, selected line, check-in), then re-renders from the main state; app lock does the same and also drops the Google token. A slow write cut by a lock fails with LOCKED in store.commit, so no success notice naming a record can reach the lock screen.
- Exports, prompts, digest, review records and backups use `mainState()`. Ledger preview and duplicate detection use the open-or-closed view, so nothing about private entries is revealed while closed.
- Passphrase and key fields: type password, cleared after success; API key never rendered (placeholder plus last 4), never in an attribute. Wrong private passphrase backoff on the open form.
- File inputs: size checked before FileReader (5 MB CSV and ledger, 64 MB backup); results ignored if the app locked meanwhile. Object URLs revoked after 1.5 s.
- Error text: `friendly()` passes core messages, which are fixed strings with labels and limits only; ledger rejection reasons carry no cell content; OAuth return errors are fixed strings.
- Auto-lock: idle timer plus wall-clock check on visibility, focus, pageshow and every 10 s; private vault closes on hidden, its own timer, app lock and before AI calls; Lock stays clickable while busy.
- 390 px: no horizontal overflow on Dashboard (Customize), Work, Revenue, Home, Admin (review-ui P4) or the screens the existing smokes cover.
