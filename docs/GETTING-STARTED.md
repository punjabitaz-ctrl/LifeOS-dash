# Getting started

The steps for a new vault, in order. The same list is in the app: Settings, "Getting started", and the setup checklist. Each step names the doc that holds the detail.

The app also has a tour of the screens (the getting started guide). It starts by itself the first time a vault opens on the Overview, and Settings, "Rerun getting started guide", starts it again. See [TOUR.md](TOUR.md).

1. Choose a passphrase. It has 12 or more characters and is set when the vault is created. See [FIRST-RUN.md](FIRST-RUN.md).
2. Turn on the recovery key and fill in the recovery sheet. The setup checklist offers "Turn on now" and "Later"; "Later" keeps it on the checklist until it is done or the checklist is dismissed. See [RECOVERY.md](RECOVERY.md).
3. Turn on persistent storage and make the first backup, from Settings. See [FIRST-RUN.md](FIRST-RUN.md).
4. Install on phone and PC from the browser menu. See [FIRST-RUN.md](FIRST-RUN.md).
5. Set up Drive sync. See [SYNC-SETUP.md](SYNC-SETUP.md).
6. Set up the private vault. When it is created, a prompt offers its own recovery key ("Turn on now" or "Later"). See [RECOVERY.md](RECOVERY.md).
7. Set up your own AI, or use none. See [AI-SETUP.md](AI-SETUP.md).
8. Enter the first records in each area. Enter them by hand first; where an area has a CSV import, it is on that area's screen.
9. Do the weekly review from the Review screen.
